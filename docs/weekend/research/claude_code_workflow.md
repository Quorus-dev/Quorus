# Teardown: Claude-Code-Workflow

## Core Architecture & Mechanism
An opinionated agentic workflow standardizing interactive terminal coding sessions with Claude, emphasizing rigorous test-driven development, automated git worktree isolation, and continuous validation loops.

## What It Does Better Than Quorus
- **Strict TDD Enforcement:** Refuses to apply code changes without an empirically reproduced test failure first.
- **Concise Iteration Loops:** Streamlined prompt-to-verification cycles optimized for minimal token waste and high execution velocity.

## What Nobody Else Does (Unique Innovations)
- **Built-in Self-Correction Heuristics:** Automatically analyzes compilation errors and test tracebacks to iteratively adjust strategies up to 3 times before escalating to the user.

## Takeaways for Quorus
Embed our strict Research -> Strategy -> Execution TDD enforcement and 3-strike self-correction rules directly into agent operating guidelines.
